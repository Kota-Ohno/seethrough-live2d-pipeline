# リギング前の失敗切り分け

局所修正の前に所有者を特定する。元の候補と失敗試案を保持し、数値上の一致と外観を別に評価する。

| 症状 | 最初の識別確認 | 対応 | 避ける対応 |
|---|---|---|---|
| 顔の輪郭がギザギザ | 顔と眼周辺補正を別々に隠し、同じ原寸箇所を見る | 凹凸がある所有者だけを補修 | 顔だけを何度も平滑化 |
| 輪郭の一部だけぼける | 下地の透明度と処理終端を確認 | 元の形を保持する透明度処理、可視の継ぎ目を確認 | 顔全体をシャープ化 |
| 肌がへこむ | 新旧50%透明度マスクと、追跡対象が髪でないかを比較 | 元の輪郭を参照し、方法を変更 | 暗い線を追う範囲をさらに広げる |
| 移植箇所が帯状になる | 元と補完画像の色、端の混合、閉眼時を比較 | 色と透明度の役割を分離 | 見た目を隠すための広範囲ぼかし |
| 閉眼時に三角形や開眼の影が残る | 開眼・閉眼正本、補正層の所有者を比較 | 文脈に沿って領域を分類し直す | 孤立画像だけを見て髪へ移す |
| 視線で灰色領域が動く | 瞳と影を独立表示、マスク依存は維持 | 瞳・ハイライトと固定影を分離 | 灰色を全削除 |
| 首に顎線や白い縁が残る | 顔を隠す。生の分解出力と移植後を比較 | 顎は顔、襟は襟、首は下地へ分離 | 首へ正本全体を再投影 |
| 髪を隠しても衣服に髪が残る | 重なる衣服パーツを個別に確認 | 同じ補完画像・登録で両方を修正 | 一枚だけ硬い矩形で差し替え |
| 色合わせ後に緑の縁が出る | 最終画像を明暗背景で確認、暗部の色補正量を確認 | 条件を限定して最終段で色漏れ対処 | 生の切抜きがきれいだから問題なしとする |
| 触角の根元や接続が不自然 | 左右別の元絵、接続部、原寸先端を比較 | 個別登録と元の共通内部の保全 | 左右ミラー複製や全体色合わせだけで合格 |
| 高解像度なのに細部が粗い | 最大表示サイズと部品の実細部、元入力の寸法・経路を確認 | 高解像度の元入力へ戻るか、不足する部品だけ再生成・超解像を比較 | 大きなキャンバスや拡大率だけを根拠にする、十分な素材にも一律再処理 |
| PSDが大きいが中身を証明できない | 実PSDのラスタ・座標・状態を読み戻す | 保存画像との全状態比較 | ファイル存在だけで完了 |
| 検証は通るがユーザが不自然と感じる | 試験の対象が画素一致か外観かを確認 | 外観は未承認として診断を更新 | テスト成功を理由に指摘を却下 |

同じ方法で二回失敗したら、別の原因仮説または方法へ切り替える。変更の少なさや試験の通りやすさではなく、指摘された状態が実際に良くなるかを判断する。
